## 支付宝捐赠

如果 Halmify 对你有帮助，欢迎通过支付宝自愿捐赠，支持项目维护、文档完善和持续改进。捐赠金额由你自行决定，使用项目无需捐赠。

打开支付宝扫一扫，或保存下方图片后在支付宝中从相册识别。二维码原图可以通过图片下方的链接打开。

## Donate with Alipay

If Halmify helps you, a voluntary Alipay donation can support project maintenance, documentation, and continued improvements. You choose the amount; no donation is required to use the project.

Scan the QR code with the Alipay app, or save the image and select it from the app's photo scanner. Use the link below to open the full-size image.
